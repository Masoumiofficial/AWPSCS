# APEX Ω — Advanced WordPress Statistics Control System

**نسخه:** 1.0.0 | **نویسنده:** اتحاد وردپرس | EtehadWP | **PHP:** 7.4+ | **WP:** 5.8+ | **مجوز:** GPLv2

افزونه مستقل، امن، سبک و قابل توسعه برای مدیریت دقیق آمار هر نوشته — به‌ویژه آهنگ — با تمرکز بر **بازدید (`views`)** و **امتیاز ستاره‌ای kk Star Ratings**.

<p align="right">رابط کاملاً فارسی و راست‌چین، طراحی استاندارد وردپرس، بدون وابستگی به قالب.</p>

---

## ✨ ویژگی‌های کلیدی

- **کشف خودکار ساختار kk Star Ratings** — هیچ کلید متا بدون بررسی پایگاه داده فرض نمی‌شود (`_kksr_casts`, `_kksr_ratings`, `_kksr_avg` تنها سرنخ هستند).
- **مدیریت بازدید (`views`)** با حفظ سازگاری قالب؛ آرشیو مقدار واقعی در `_apex_real_views`.
- **متاباکس ویرایش هر نوشته** — تعیین دستی میانگین (0 تا سقف ستاره)، تعداد رأی و بازدید، حالت manual/scheduled/disabled، پیش‌نمایش تغییرات.
- **صفحه ویرایش گروهی** برای مهاجرت و مقداردهی اولیه.
- **موتور زمان‌بندی هوشمند** — بازه شروع/پایان، فاصله اجراها، سقف مطلق و درصد هر گام، حداقل/حداکثر کلی، توقف/ادامه/لغو.
- **ضد نوسان** — کاهش بزرگ (>۲۰٪) نیاز به تأیید جداگانه؛ جهش >۵۰٪ هشدار بحرانی؛ تغییر خارجی ناگهانی → `needs_review`.
- **تاریخچه کامل + بازگردانی** — هر تغییر با `execution_id` یکتا، کاربر، IP و منبع؛ بازگردانی تک‌کلیک.
- **امنیت سخت‌گیرانه** — capability `apex_manage_statistics`، nonce، sanitize/escape، prepared statements، قفل DB، تراکنش.
- **سازگاری کش** — پاکسازی WP Rocket / W3TC / LiteSpeed پس از هر تغییر.
- **WP-Cron آگاه** — مستندات کامل + پشتیبانی Cron واقعی سرور هر ۵ دقیقه.

## 🚀 نصب

1. پوشه `apex-omega` را در `wp-content/plugins/` آپلود کنید.
2. از پیشخوان → افزونه‌ها → **APEX Ω** را فعال کنید.
3. منوی جدید **آمار پیشرفته** ظاهر می‌شود.

## 🎛️ پیکربندی سریع

1. **داشبورد** وضعیت kk، تعداد برنامه‌ها و هشدارها را ببینید.
2. **ویرایش یک آهنگ** → متاباکس APEX Ω → مقادیر جدید → تأیید جهش اگر لازم → ذخیره دستی.
3. **زمان‌بندی:** حالت را `زمان‌بندی‌شده` کنید → فیلد هدف/شروع/پایان/فاصله را پر کنید → پیش‌نمایش → ایجاد برنامه.
4. **تاریخچه:** هر ردیف را می‌توانید بازگردانی کنید.

## 📊 مدیریت آمار هر آهنگ (متاباکس)

- میانگین هدف (0 تا best، معمولاً 5)
- تعداد رأی مبنا (INT ≥0)
- بازدید مبنا (INT ≥0، حداکثر 100M)
- حالت: دستی / زمان‌بندی‌شده / غیرفعال
- فاصله زمانی، سقف هر اجرا (عدد و درصد)، حداقل/حداکثر کلی
- توقف/ادامه/لغو، تاریخ آخرین تغییر، پیش‌نمایش

> تمام ورودی‌ها اعتبارسنجی می‌شوند: خالی/منفی/اعشاری برای شمارشی/بیش از ظرفیت مسدود است.

## ⏱️ زمان‌بندی

- هر پست برنامه مستقل دارد.
- مثال: فعلی ۱۰۰٬۰۰۰ هدف ۱۱۰٬۰۰۰ → با سقف ۵۰۰ هر ۳۰ دقیقه در ۷ روز به‌تدریج می‌رسد.
- مثال اشتباه: فعلی ۱۰۰٬۰۰۰ هدف ۵۰٬۰۰۰ → ۵۰٪ کاهش → سیستم هشدار و تأیید می‌خواهد؛ بدون تأیید اجرا نمی‌شود.

WP-Cron تضمین ساعت دقیق نمی‌دهد؛ برای دقت:

```bash
*/5 * * * * wget -q -O - https://example.com/wp-cron.php?doing_wp_cron >/dev/null 2>&1
```

## 🔍 سازگاری kk Star Ratings

APEX در هر درخواست با نمونه‌برداری از `wp_postmeta` کلیدهای واقعی را می‌یابد. اگر افزونه فعال نباشد، مدیریت دستی ممکن است اما نمایش فرانت نیاز به kk دارد. فرمول میانگین:

```
avg = round( ratings / casts / 5 * best , 1 )
```

`_kksr_avg` صرفاً legacy است؛ منبع حقیقت `casts` و `ratings` هستند.

## 📜 تاریخچه و بازگردانی

- هر تغییر: `post_id, field_type, old, new, delta, source, user_id, execution_id`
- منابع: `manual, scheduled, bulk_manual, restore, real_vote, external_change`
- رأی واقعی جدید → برنامه‌های kksr آن پست به `needs_review` می‌روند.
- بازگردانی تکراری با قفل محافظت می‌شود.

## 🔒 امنیت

- capability `apex_manage_statistics` + `manage_options`
- nonce همه فرم‌ها/AJAX
- sanitize/escape، prepared statements، transactional writes
- قفل `wp_apex_omega_locks` علیه race
- غیرفعال‌سازی آمار اصلی را حذف نمی‌کند؛ uninstall فقط با گزینه صریح جداول APEX را پاک می‌کند.
